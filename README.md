# Networking Labs & Learning Portfolio

## Overview

This repository serves as documentation of my continuous learning and practical development in computer networking. It contains hands-on laboratory exercises, network configurations, implementation scenarios, and troubleshooting activities.

Through these exercises, I aim to strengthen my understanding of networking concepts and develop practical skills in configuring, managing, and troubleshooting network infrastructures.

## Technologies & Tools

- **Cisco Packet Tracer** – Network simulation and configuration
- **GNS3** – Network emulation and practical lab environments
- **Cisco IOS** – Network device configuration and management

## Laboratory Activities

This repository includes practical exercises focused on:

- Network design and implementation
- Device configuration and management
- Network connectivity testing
- Routing and switching implementation
- Network services configuration
- Troubleshooting and problem-solving

## Learning Objectives

- Develop a strong foundation in computer networking.
- Apply theoretical networking concepts through practical exercises.
- Gain experience configuring and managing network devices.
- Improve troubleshooting and problem-solving skills.
- Explore network technologies used in enterprise environments.

## Repository Purpose

This repository will continue to evolve as I explore new networking concepts, complete laboratory exercises, and expand my technical knowledge.
